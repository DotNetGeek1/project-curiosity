## Purpose

This folder translates the product definition and foundation rules into page-level behaviour.

The specifications describe what a reader should understand, what actions should be available, how information is prioritised and how the experience adapts across devices and accessibility needs.

## Rules

- Page specifications must extend, not contradict, ADR-001.
- Clear document structure takes priority over novelty.
- Core reading and navigation must work without client-side JavaScript.
- Decorative behaviour must not block access to content.
- Every page must support a useful shallow read and a rewarding deep read.
