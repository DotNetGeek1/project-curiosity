# DotNetGeek Portfolio — Vision

## Mission

Build an engineering notebook rather than a portfolio.

The site should answer one question:

**"How does Alex think?"**

It is a collection of experiments, engineering stories and research notes.

## Core Narrative

Everything starts with:

> I wondered if...

Projects exist because of curiosity, not because they were needed for a CV.

## Success Criteria

- Visitors understand how Alex approaches problems.
- Every project tells a story.
- Technology supports the narrative rather than leading it.
- The site feels like walking into an engineer's workshop.
