# Design Language

Mood:

- Engineering notebook
- Research journal
- Physics lab
- Museum archive

Avoid:

- Neon
- Glassmorphism
- SaaS gradients
- Flashy animation

Palette:
Warm paper
Charcoal
Muted earthy accents

Typography:
Editorial serif
Readable sans
Mono for technical metadata

Motion:
Subtle.
Animation should explain, never entertain.
