# References

This folder records sources that influence the product, content, visual language or technical decisions.

References are inspiration and research, not instructions to copy another product.

Create focused notes such as:

- `editorial-design.md`
- `technical-writing.md`
- `diagram-language.md`
- `portfolio-analysis.md`
- `accessibility-patterns.md`
- `interaction-patterns.md`

Each reference note should record:

1. source and access date;
2. what is relevant;
3. what should not be copied;
4. which Project Curiosity documents it may influence.

Do not commit copyrighted assets without permission.
