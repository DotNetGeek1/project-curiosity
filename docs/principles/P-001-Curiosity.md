> Every meaningful experiment starts with a question, not a technology.

I do not choose a framework and then search for a reason to use it. I start with something that bothers me, interests me, or appears possible but untested.

Curiosity is useful only when it moves beyond collecting ideas. The expected path is:

1. notice;
2. question;
3. investigate;
4. build enough to learn;
5. follow the evidence;
6. stop, iterate or ship.

The site should preserve that movement. It should not rewrite every project as a smooth success story.

Curiosity also explains the breadth of technology across my work. I learn new tools because the problem requires them, not because a skills list has an empty space.

## Test

A project belongs in the notebook when it contains a worthwhile question, meaningful investigation and learning that another person can understand.

A repository does not belong merely because it exists.
