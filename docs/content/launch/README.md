## Purpose

This folder contains the first implementation-ready copy pack for Project Curiosity.

The documents are not a substitute for the structured content files that will ultimately live under `content/`. They define the approved narrative, wording boundaries, metadata and placeholders that Cursor or another implementation agent may convert into site content without inventing new claims.

## Documents

- `HOME-COPY.md` — homepage copy by section.
- `ABOUT-COPY.md` — first-person About page copy and supporting fragments.
- `EXPERIMENT-INDEX-COPY.md` — index introduction, card summaries and labels.
- `GLOBAL-COPY.md` — navigation, footer, empty states and utility copy.
- `SEO-AND-SOCIAL-METADATA.md` — page titles, descriptions and social-preview guidance.
- `CONTENT-PLACEHOLDERS.md` — approved placeholder language for evidence not yet collected.
- `LAUNCH-COPY-REVIEW.md` — factual, tone and publication review checklist.

## Rules

1. All personal copy uses `I`, `me` and `my`.
2. Copy must remain consistent with `WRITING-RULES.md` and ADR-001.
3. Unverified claims must not be promoted into published prose.
4. Placeholders must remain visibly provisional.
5. Coding agents may adapt copy for layout but must not change meaning silently.
